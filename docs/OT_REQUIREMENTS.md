## 1. 기능 우선순위

### 1순위: 진로로드맵 구축·관리

**(1) 계획수립**
- 1~4학년 전 학기 계획. 교과·비교과·학사제도(마이크로디그리 등)·교외활동(어학시험, 인턴 등)을 학기별로 배치한다.
- 희망 진로 + 1·2트랙 기준.
- 실제 학기별 개설 과목·비교과 목록을 사용한다.
- 체크박스·드래그 앤 드롭 UI.
- 졸업 후 5년 계획(자격증·시험·대학원·취업·이직 준비)을 글로 입력한다.
- 이수 여부 입력 → 달성률 표시(졸업학점, 비교과포인트, 로드맵 진행률).
- 졸업요건 필터링: 이수구분별 필요 학점, 학기당 수강신청 상한, 졸업학점 달성률 등.

**(2) 계획공유**
- 희망 전공 조합별로 로드맵을 여러 개 만들고, 대표 로드맵을 정한다.
- 익명 공개. 남의 로드맵을 검색·조회·가져오기.
- 학과·전공·트랙별 추천 로드맵, 우수 로드맵(많이 가져간 것, 우수 졸업생 것)을 상단에 노출한다.
- "성공 로드맵 진로 멘토 리스트": 졸업동문·재학생의 진로, 소속, 1·2트랙 조합, 연락.

**(3) 계획실행**
- 학기 중 계획한 교과·비교과·학사제도·교외활동 현황을 모니터링하는 대시보드.

**(4) 결과확인**
- 대표 로드맵 + 이수내역을 한 서식으로 추출한다(상담 기초자료).
- 최종 포트폴리오 추출(인포그래픽, 자소서 준비용).

### 2순위: 학과·전공·트랙 추천
- 진로적성검사(고용24)나 자체 테스트 기반 추천.
- 이수내역·유사 사용자 기반 추천.
- 1·2트랙 조합별 비교(교육목표, 진로, 커리큘럼, 졸업요건).
- 트랙 조합별 커뮤니티.

### 3순위: 관리자 대시보드
- 로드맵 데이터와 사용 기록(빈도, 시점) 누적·분석·추출.
- 추천·우수 로드맵 업로드.
- 활용 방안.

## 2. 평가 기준
- 센터 요청사항을 그대로 반영하지 말 것. 학생 관점에서 불필요한 기능은 빼고 필요한 기능은 더하며, 이유를 설명한다. 독창적 기획·활용방안.
- 안정성·유지보수: 신입생 약 1,400명이 사용하고, 매년 신입생+재학생 로드맵이 쌓이는 규모를 고려한다.
- 모든 기능을 구현할 필요는 없다. 기능별 결과물도 가능하다. 단 진로로드맵이 1순위.

- 결과물: 시연 가능한 웹앱 접속 링크.

# 설계 결정 기록

큰 결정을 하면 한 줄씩 남긴다. 나중에 "이거 왜 이렇게 했지?"를 막기 위한 기록이다.

| 날짜 | 결정 | 이유 |
|---|---|---|
| 2026-11-21 | Next.js(App Router) + TypeScript + Tailwind, Vercel 배포 | 화면·서버·AI 호출을 한 레포에서 관리, 바이브코딩 자료가 가장 많음, 학생성공·전공설계센터도 Vercel로 웹앱 운영 중 |
| 2026-11-21 | 프로토타입에 DB·로그인 없음, 이수 내역은 localStorage | 기획서 약속("입력 정보는 본인 기기에만 저장"), 개인정보 위험 최소화 |
| 2026-11-21 | 학교 규칙은 `data/rules/*.csv` 로 분리 | 기획서 약속("학사 개편 시 담당 부서가 표를 직접 수정"), AI가 규정을 지어내지 못하게 |
| 2026-11-21 | 졸업요건 판정은 규칙 엔진, AI는 진로 분석·설명만 | 신뢰 설계: 판정 결과를 언제든 근거로 설명 가능해야 함 |
| 2026-11-21 | Claude 설계·리뷰, Codex 구현 | 역할 분리로 AI끼리 같은 실수를 반복하지 않게 |

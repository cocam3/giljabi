# 길잡이

진로에서 출발해 트랙 선택, 학기별 로드맵, 졸업까지 이어 주는 한성대학교 전공 설계 웹앱.
2026 HSU 진로로드맵 e-Advisor 웹앱 개발 공모전 출품작 · 팀 코캠(cocam)

- **찾다**: 희망 진로·채용공고로 맞는 트랙·모듈 추천
- **짜다**: 학기별 로드맵 작성 + 졸업요건 실시간 검사
- **지키다**: 트랙 변경·휴학·조기졸업 시뮬레이션

## 처음 왔다면 읽을 순서
1. `AGENTS.md` — 모든 사람·AI가 지키는 규칙
2. `docs/TEAM_GUIDE.md` — 작업 흐름과 하지 말 것
3. `docs/PROMPTS.md` — Claude·Codex에 그대로 쓰는 프롬프트
